Trabajo práctico integrador de Introducción al Análisis de Datos - UTN Avellaneda.

## De qué se trata

Una empresa de telefonía e internet está perdiendo clientes. Con los datos de unos 7000 clientes (qué
servicios tienen, cuánto pagan, qué contrato tienen, etc.) tratamos de ver qué tienen en común los que
se dan de baja (churn), para que la empresa pueda hacer algo para retenerlos.
